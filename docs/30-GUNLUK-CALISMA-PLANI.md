# Teknik Servis ve Talep Takip Sistemi — 30 Günlük Çalışma Planı

## 1. Hafta — Analiz ve veritabanı
1. Geliştirme ortamı ve Git kurulumu.
2. Talep açma-atama-çözüm-kapatma akışının analizi.
3. Kullanıcı, kategori ve talep tablolarının tasarımı.
4. Primary Key, Foreign Key ve ilişkilerin oluşturulması.
5. SQL sorguları ve temel stored procedure çalışmaları.

## 2. Hafta — Backend mimarisi
6. ASP.NET Core projesinin oluşturulması.
7. Entity Framework Core ve SQL Server bağlantısı.
8. Talep CRUD işlemlerinin geliştirilmesi.
9. Katmanlı mimari ve repository yaklaşımının incelenmesi.
10. Hata yönetimi ve doğrulama.

## 3. Hafta — İş mantığı ve güvenlik
11. Talep oluşturma kurallarının eklenmesi.
12. Kullanıcı kayıt ve JWT login işlemleri.
13. Admin, teknik personel ve kullanıcı rollerinin ayrılması.
14. Şifrelerin hashlenerek saklanması.
15. Postman ile API testleri.

## 4. Hafta — Modüller
16. Talep oluşturma modülü.
17. Dosya yükleme altyapısının planlanması.
18. Yönetici tarafından talep atama.
19. Cihaz seri numarası eşleştirme.
20. Talep yorumları ve mesajlaşma.

## 5. Hafta — Arayüz
21. Bootstrap arayüz planı.
22. Talep listeleme ve sayfalama.
23. Form doğrulama.
24. AJAX ile durum güncelleme.
25. Profil ve kullanıcının talepleri ekranı.

## 6. Hafta — Raporlama ve teslim
26. Dashboard istatistikleri.
27. Tarih, durum ve personel filtreleri.
28. Senaryo testleri ve hata düzeltmeleri.
